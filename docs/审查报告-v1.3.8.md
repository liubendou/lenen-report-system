| 级别 | 问题 | 修复 |

## 八、v1.3.6 手机端修复（用户报"手机端登录界面都不显示"）

| # | 原因 | 修复 |
|---|---|---|
| 1 | **v1.3.5 新加的安全头把手机端锁死了**：全局 `X-Frame-Options: DENY` + 入口页 `frame-ancestors 'none'`——手机经隧道/预览页（iframe 嵌入）访问时，浏览器直接**拒绝渲染整页**，表现就是"什么都不显示" | 移除这两个头（保留 nosniff、Referrer-Policy、CSP 其余指令、API no-store）；内网工具系统防点击劫持价值低，可用性优先 |
| 2 | **登录/注册页输入框是组件库控件且无降级**：手机弱网或旧浏览器组件加载失败时，输入框全部不可见 | 登录/注册页对齐改密页的防御式做法：组件就绪用组件，不就绪自动降级原生输入框/按钮，弱网必达 |
| 3 | 登录盒固定宽 350px，窄屏（<382px）横向溢出 | 加 max-width: 100% |

测试同步更新（full 215/ smoke 41/ audit 213 全绿，新增"无 XFO / 不锁 iframe / 降级代码在位"断言）；生产实测：version=1.3.6、入口页无 XFO、CSP 无 frame-ancestors、新资源 ?v=8 生效。

**教训已记入审查 skill**：安全头类改动必须先确认真实访问路径（本项目存在 iframe 隧道/预览访问），"最佳实践"不问场景会直接弄坏用户。
